# 로드맵 — 로컬 우선 카드뉴스 스튜디오

목표: 누구나 자기 컴퓨터에서 바로 돌리고, **이미 쓰는 Claude·ChatGPT 구독**으로 기획·초안까지 시킬 수 있는 카드뉴스 스튜디오.

| # | 할 일 | 상태 |
|---|---|---|
| 1 | 클라우드 노출 제거: 임시 터널 끄기, 터널 허용 설정 빼기 (OAuth 코드는 남김 — 로컬 앱·나중 배포용) | 진행 |
| 2 | 로컬 구독 연결: 'AI 앱 연결'을 로컬에서 되는 순서로 — Claude Code(개인 토큰) · Claude Desktop(로컬 MCP 다리) · Codex CLI(ChatGPT 로그인) · 웹 커넥터는 '배포했을 때' | 진행 |
| 3 | 한 번에 설치: `pnpm setup:local` — `.env.local` 무작위 값 만들기 + 데모 데이터(STUDIO) 깔기 | 진행 |
| 4 | 공개 저장소: 깨끗한 새 기록(개인·운영 데이터 없이)으로 GitHub 공개, README·글꼴 라이선스 | 진행 |
| 5 | CI: 타입 검사·lint·빌드 (GitHub Actions) | 진행 |
| 6 | 새로 받아서 돌리기 확인: 공개 저장소를 새로 clone → 설치 → 빌드 | 진행 |
| 7 | 구독으로 실제 쓰기 확인: Claude 구독(Claude Code)으로 러닝 크루 서비스 카드뉴스 초안 만들기 → 브라우저로 확인 | 진행 |
| 8 | 디자인 캔버스·문서 맞추기 | 진행 |
