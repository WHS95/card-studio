## 확인 결과 (2026-10-06)
- 공개 저장소를 새로 clone → `pnpm setup:local` → 타입 검사·빌드 통과, GitHub Actions CI 통과.
- Claude Max 구독의 Claude Code(API 키 없음)가 MCP 로 러닝 크루 서비스와 카드뉴스 초안 2개(뉴스형·포스터형)를 만들었다. 승인은 하지 않았고, 모르는 일정·장소는 [확인 필요]로 남겼다.
- 같은 구독으로 '편집자' 계정 개인 토큰을 쓰면 그 서비스만 보이고, 승인은 거절되고, 다른 서비스는 숨겨진다.
- 점검 중 발견해 고친 것: 흑백 기본 테마에서 '강조색 글자' 강조가 안 보이던 것 → 강조색이 밝으면 채움으로.
