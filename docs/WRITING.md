# 문구 규칙 (UX 라이팅)

## 지향 (보이스)

명확하게 · 간결하게 · 친근하게 · 존중하며 · 공감하며. 읽는 사람이 한 번에 알아듣고, 속지 않고, 스스로 고를 수 있게 써요.

## 규칙

| # | 규칙 | 이렇게 | 자동 검사 |
|---|---|---|---|
| 1 | 해요체로만 | '~합니다' → '~해요' | 고칠 것(fix) |
| 2 | 줄여 쓰기 | 되어요 → 돼요, 되었어요 → 됐어요 | fix |
| 3 | 과한 경어 빼기 | ~시겠어요 → ~할래요? · 계시다 → 있다 · ~께 → ~에게 · 여쭈다 → 묻다 | fix |
| 4 | 능동형 | ~하게 됐어요 → ~했어요 (단, 종료·만료·안심시킬 때는 수동형도) | 살펴볼 것(tip) |
| 5 | 명사 덩어리 풀기 | 이용 가능 → 쓸 수 있어요 · 진행 예정 → 할 거예요 | tip |
| 6 | 빼도 되는 말 지우기 | 혹시 · 앞으로 · 일단 · 다양한 · 여러 가지 | tip |
| 7 | 강요·겁주기 대신 권유 | ~해야 해요 · 놓치면 손해 · 마지막 기회 → ~할 수 있어요 | tip |
| 8 | 과장 대신 사실·숫자 | 최고 · 역대급 · 완벽 · 대박 | tip |
| 9 | 모두가 아는 말 | 유행어·은어·밈·업계 용어 대신 쉬운 말 | tip |
| 10 | 긍정형 먼저 | 안 돼요 → ~하면 할 수 있어요 (정책·안전은 분명하게 부정형) | tip |
| 11 | 한 문장에 메시지 하나 | 70자 넘는 문장은 나누기 | tip |
| 12 | 느낌표는 하나 | !! → ! | tip |

검사로 못 잡는 것(사람·AI 가 지킬 것):
- **다음이 보이게**: 행동 유도는 할 일을 구체적으로(예: '댓글로 내 페이스 남기기').
- **핵심 하나**: 표지·홍보 문구는 지금 할 이유 하나만. 장마다 메시지 하나.
- **확실한 것**: 크고 불확실한 혜택('최대 ○○')보다 확실히 받는 것.
- **가볍게·구체적으로**: 가입 → 준비, '빈칸 채우기' → '8칸 채우기', '3분이면 돼요'.
- **일상 동작 말**: 찍기·담기·저장하기처럼 실제로 하는 행동.
- **같은 말 되풀이·자리 채우기 문장 지우기**, 소리 내 읽어 어색하면 고치기.
- **공감 한 줄**: 정보 뒤 읽는 사람의 마음을 생각하기. 사실·숫자는 자료에 있는 것만.
- 도구 화면: 다이얼로그 닫는 버튼은 '취소' 대신 '닫기'(하던 일이 취소되는 것처럼 보이지 않게). 오류 문구는 상황 · 이유 · 해결책을, 사용자가 이해하는 말로.

## 어디에 걸려 있나

- **AI 가 쓰는 글**: `ai.ts` 의 모든 요청(초안·주제 제안·자료 요약)에 `WRITING_GUIDE`. AI 초안은 다 쓴 뒤 검사에서 fix 가 나오면 다듬기 등급으로 한 번 고친다(편집기 알림 '문구를 다듬고 있어요').
- **AI 패널**: `llm.ts` CHAT_SYSTEM 에 규칙 + 게시물을 고친 뒤 `check_writing`.
- **내 Claude·ChatGPT (MCP)**: 서버 안내문(`INSTRUCTIONS`)에 규칙, `update_post` 설명, 검사 도구 `check_writing`(게시물 id 또는 글 하나).
- **사람이 쓴 글**: 브리프 콘텐츠 규칙 '문구 규칙 (UX 라이팅)'(기본 켜짐) → 편집기 경고 줄·장 목록 '⚠ 문구'·제작 목록 경고 수·검수 '스튜디오가 확인한 것'.
- **템플릿 기본 문구·샘플·업종 시작 묶음**: 이 규칙으로 한 번 정리함(바꿀 때 다시 검사).

검사는 경고만 해요(저장·승인을 막지 않아요). 브랜드 말투(브리프 '말투')는 이 규칙 위에서 더해요.
